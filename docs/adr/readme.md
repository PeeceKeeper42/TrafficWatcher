## Правила связи курса и ADR

- В конце каждого урока перечислены ADR, которые он порождает; урок не закрывается, если решение
  принято «в голове» и не зафиксировано.
- Если ADR противоречит концепции ([`readme.md`](../readme.md) §1) или тематическому уроку
  (модули 8 и 19, когда будут написаны) — правится документ новым коммитом со ссылкой
  на ADR, а не молча.
- Протухание: решение поменялось → новый ADR со `Заменяет NNNN`, старый получает статус `Заменено`.
- Есть решения, которые план не принимает за меня. ADR-0030 (способ растеризации) остаётся открытым до
  замера в уроке 15.4: до принятия курс считается на штатном средстве Qt, а строка очереди живёт со
  статусом `Предложено`. Записывать в таблицу выбор, которого ещё не было, нельзя.
