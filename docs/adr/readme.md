## Правила связи курса и ADR

- В конце каждого урока перечислены ADR, которые он порождает; урок не закрывается, если решение
  принято «в голове» и не зафиксировано.
- Если ADR противоречит концепции ([`readme.md`](../readme.md) §1) или тематическому уроку
  ([`08-testing-strategy.md`](../lessons/08-testing-strategy.md),
  [`15-infrastructure.md`](../lessons/15-infrastructure.md)) — правится документ новым коммитом со ссылкой
  на ADR, а не молча.
- Протухание: решение поменялось → новый ADR со `Заменяет NNNN`, старый получает статус `Заменено`.
